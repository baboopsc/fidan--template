# TaskPro

TaskPro is a task management application that helps users organize projects using boards, columns, and task cards.

## Features

- User registration and authentication with JWT
- Create, edit, and delete boards
- Create, edit, and delete columns
- Create, edit, delete, and move tasks between columns
- Task priorities, descriptions, and deadlines
- Persistent workspace storage
- Responsive dashboard layout

## Tech Stack

### Frontend
- React
- React Router
- Redux Toolkit
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Swagger API Documentation

## Deployment

- Frontend: GitHub Pages
- Backend: Render
- Database: MongoDB Atlas

## Install dependencies:

### Frontend:
- cd frontend
- npm install
- npm run dev

### Backend:
- cd backend
- npm install
- npm run dev
